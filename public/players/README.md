# Player Photos Directory

Because of copyright, real player portraits are not included in this repository.
Please place your authentic `.png` or `.jpg` player photos in this folder.

Ensure the file names map correctly to the `photo_url` in your Supabase `players` table.

Example:
If your Supabase `photo_url` is `/players/3004.jpg`, you must place an image named `3004.jpg` in this directory.
