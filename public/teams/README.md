# Team Logos Directory

Because of copyright, team logos are not included in this repository.
Please place your authentic `.png` or `.jpg` team logos in this folder.

Ensure the file names map correctly to the `logo_url` in your Supabase `teams` table.

Example:
If your Supabase `logo_url` is `/teams/Olympiacos.png`, you must place an image named `Olympiacos.png` in this directory.
